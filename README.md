# Appium Mobile Automation Framework

A **reusable mobile automation framework** built with **Java and Appium**, featuring sample test automation for the **Vani Coach** application, including **Homepage and Login** test scenarios.

The framework provides the **basic Appium setup and project structure**, so it can be reused for other mobile automation projects without building the foundation from scratch.

## 🛠️ Tech Stack

* **Java**
* **Appium**
* **Selenium**
* **TestNG**
* **Maven**
* **Page Object Model (POM)**

## ✨ Key Features

* ♻️ Reusable Appium framework setup
* 📱 Android mobile application automation
* 🧱 Page Object Model
* 🧪 Sample Login & Homepage test cases
* 🔧 Easy to customize and extend
* 📦 Maven-based project structure

## 🚀 How to Reuse

Clone the repository and use the existing framework setup as your foundation.

```bash
git clone https://github.com/pawanrewatkar/appium_mobile_automation.git
```

Remove the sample **Vani Coach page classes and test cases**, then add your application's:

```text
Page Classes
     ↓
Test Cases
     ↓
Locators & Actions
     ↓
Assertions
```

The basic Appium configuration and framework setup are already available, allowing you to **start writing application-specific tests immediately**.

## 🎯 Purpose

This project was created as a **self-driven R&D initiative** to build a practical, reusable foundation for **Appium-based mobile automation projects** and reduce the initial framework setup effort.
